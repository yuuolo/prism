# Prism v0.2.11

## 内核自动恢复

- 修复连接重试、背景流量持续变化时不进行联网探测的问题。启动宽限期后，每约 30 秒独立检查代理联网，不再等待连接或计数完全静止。
- 开启 TUN 时，代理端口探测正常后，还使用系统 DNS 和系统路由检查联网；覆盖代理端口正常但系统通路不通的情况。连续三轮检测失败才尝试重启，单次波动、正常空闲不触发重启。
- 保留手动停止取消、至少一分钟重启间隔及十分钟内最多三次的限制；探测期间修改恢复设置或停止内核会使旧检测失效。
- 自动重启继续由 TUN 服务替换内核，保留已启用的断网保护，不通过解除保护恢复联网。macOS 使用现有平台机制，不新增 Windows 式断网保护。

## 故障记录与设置说明

- 持久记录故障确认、失败通路、冷却、重启结果及联网恢复；总量最多 2000 条，为运行和保护事件预留容量，避免大量拒绝记录挤掉故障经过。
- 更新设置说明：无变化阈值用于诊断提示，连接和流量变化不再推迟周期联网检查。

## 更新提示

本次自动恢复修复在桌面主程序中，**必须退出旧版并启动 v0.2.11 才会生效**。仅重启旧版内核不会获得本次修复。

Windows 安装包仍包含 Prism 内核和 TUN 服务。若设置提示服务内核需要更新，请在设置中更新 TUN 服务。已有 DNS 防绕过和断网保护机制保留。

这些改动补足了故障监测盲区，不代表已确定所有长时间断网的根因。上游节点或物理网络中断时，重启也可能无法恢复；请查看新增的恢复事件记录。
