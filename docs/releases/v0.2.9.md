# Prism v0.2.9

## DNS 与 IPv6 控制

- 增加 DNS 隐私设置：代理 DoH、指定解析出口、节点引导解析、fake-IP、AAAA 应答和 IPv6 目标阻断。
- 普通域名与代理节点引导解析分离；要求代理解析时拒绝直连回退，避免订阅隐式 DNS 回退绕过设置。

## Tailscale 组网

- 新增官方客户端安装、注册/登录入口、连接与断开、设备列表和连通测试。
- Windows Prism TUN 的组网直连可与互联网断网保护共同启用。服务核验官方守护进程的安装路径、签名、发行者和 SYSTEM 身份，仅为必要的守护进程传输，以及验证接口上的具体组网设备地址添加例外。
- 断开或验证失败后撤销例外，基础互联网阻断保持生效。Prism 内断开先撤销授权；外部断开通过约 2 秒轮询发现，存在状态查询检测窗口。
- 连接阶段仅给已验证守护进程最多 60 秒临时授权，不开放组网设备流量。未完成登录可再次连接。

## 自动恢复

- 增加内核异常退出与连接/流量停滞检测，通过本机代理进行联网探测后确认故障，避免正常空闲引发重启。
- 自动恢复具有启动宽限、连续失败确认、重启间隔与频率限制；手动停止会取消旧的恢复请求，恢复事件写入日志。

## 更新与验证

Windows 用户更新后请在设置中更新/重新安装 TUN 服务，以安装新服务协议和内核；可能需要一次管理员授权。旧服务不会通过关闭断网保护来兼容共存模式。

受控防火墙共存目前仅适用于 Windows Prism 内核。Tailscale 出口节点叠加 Prism 全局 TUN 尚不作为可靠出口模式支持，请先使用设备互联。

已通过隔离 Windows 原生 WFP 规则安装与撤销测试、签名及授权测试。真实 Tailscale 双设备、实际订阅下的 DNS 泄漏和长时间休眠/切网稳定性仍需现场验证，自动恢复不能保证上游故障时联网。
