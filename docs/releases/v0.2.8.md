# Prism v0.2.8

## 稳定性与网络恢复

- 修复 AnyTLS 关闭会话后阻塞的 TLS 读写任务未主动退出的问题，清理空闲会话并限制连接池容量。
- 修复 DoH 服务器发送 Connection: close 时有效 DNS 答案被丢弃的问题；复用 DNS 连接无响应时及时尝试新连接。
- Windows TUN 检测上联网卡、网关、源 IPv4 地址变化和休眠后的时间间隔，自动重新绑定网卡、重建 DNS 与出站连接；保留 TUN、断网保护、节点选择、模式及 fake-IP 映射，失败时延迟重试。

## 功能改进

- 概览增加内核持续运行时长；日志增加持久化运行、安全和网络恢复事件及类型筛选。
- 订阅合并只进入节点选择和自动选择入口，不再向地区、业务代理组兜底添加节点。
- 加强 TCP/UDP DNS 拦截，拒绝隐式系统 DNS 回退。使用域名 DNS 上游时请显式配置 default-nameserver。
- 订阅页增加单节点导入，节点独立保存在本地，避免远程订阅更新覆盖。
- 连接页增加协议、出口筛选和多字段升降序排序，地图与导出沿用筛选结果。

## 更新提示

Windows 更新后请在设置中更新/重新安装 TUN 服务，确保服务独立保存的内核也更新到本版本。可能需要一次管理员授权。

Windows 的网络自动恢复针对 IPv4 上联；macOS 包包含通用 AnyTLS/DNS 修复与界面功能，不包含此次 Windows 专用网卡监控。

本机已通过 83 项内核单元测试、6 项 AnyTLS 集成测试、20 次重复恢复集成测试及 release 内核 21 次代理收发测试。实际订阅下的休眠/切网和长时间稳定性仍需持续验证。
