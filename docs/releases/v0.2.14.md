# Prism v0.2.14

## 界面精简与按需帮助

- 设置、订阅、应用分流、域名/IP 分流、真实 IP、链式代理、Tailscale 组网及测速等页面的长说明默认折叠，点击“？ / 帮助”查看完整内容。
- 同一区域的相关说明合并到帮助入口，减少重复文字；DNS 上游、节点引导 DoH、联网探测地址等标签精简，填写要求保留在帮助中。
- 关键状态、保护提示及输入错误继续直接显示，不会被帮助面板隐藏。
- 帮助入口支持键盘聚焦、回车展开/收起，并补齐英文界面文案。

## 安装与更新

- 提供 Windows x64、macOS Intel 和 Apple Silicon 安装包，继续使用现有签名更新通道。
- 可在客户端检查更新，或下载对应平台安装包。安装后完整退出并重新打开 Prism。
- **使用 TUN 的用户请按提示在设置中“重新安装 / 更新内核”，同步 TUN 服务保存的内核副本。**

本版保留 v0.2.13 的内核、TUN 和服务恢复改进；这次界面调整不代表长期稳定性测试已经完成。
