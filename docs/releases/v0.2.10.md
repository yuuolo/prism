# Prism v0.2.10

## Windows DNS 与启动修复

- TUN 自动路由新增独立的 DNS 防绕过规则，限制普通程序的 IPv4/IPv6 TCP/UDP 53 查询只经 TUN，阻止物理网卡及局域网 DNS 旁路。此保护独立于互联网断网保护开关；内核自身必要的上游连接保留，DNS 配置决定其代理或直连出口。
- 修复网卡尚处于 Tentative 状态就报告 TUN 启动完成的问题。先启用 Wintun 会话，等待 IPv4/IPv6 地址完成重复地址检测、进入 Preferred 状态后才报告就绪；冲突和超时明确报错。
- 防绕过规则随 TUN/内核退出清理，热重载和上联网卡变化期间保留。

## 共用 DNS 设置

- 新安装或缺少 DNS 保护设置时，默认开启 DNS 覆盖及经代理的 DoH。已经明确保存的关闭状态仍保留；代理出口不可用时不回退直连。
- 自带 DoH/DoT 的应用仍按普通连接分流，不会被 53 端口规则自动识别。

## 平台范围

本次系统层 DNS 防绕过和地址就绪修复仅适用于 Windows。macOS 包包含共用 DNS 默认设置改进，但不包含 Windows WFP 防护，不能据此宣称 macOS 的所有 DNS 泄露场景已经修复。

Windows 已通过隔离环境的实际 IPv4/IPv6 TCP/UDP 收包、接口与内核例外、普通流量、退出清理，以及真实 Wintun 的 DNS、热重载和地址就绪测试。现场已复现 v0.2.9 系统 DNS 查询在返回 fake-IP 的同时仍被运营商解析器查询；新版本在不同实际网络和浏览器下的效果仍需持续复测。

## 更新提示

Windows 更新后请在设置中更新/重新安装 TUN 服务，确认实际运行内核为 **0.2.10**。启用 TUN、DNS 覆盖和“DNS 经代理查询”，保存后使用原节点复测。仅更新主程序不足以替换服务独立保存的内核副本。
