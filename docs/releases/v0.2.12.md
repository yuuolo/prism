# Prism v0.2.12

## Windows：断网保护应用例外

- 设置 → TUN 服务 → 断网保护新增应用例外，可填写本地 `.exe` 完整路径，或从运行中的程序选择；最多 32 个，支持添加和移除。
- 精确匹配可执行文件路径，不按同名进程放行，不接受目录、通配符或网络共享路径。服务和子进程需要分别添加。
- 保存后同步新版 TUN 服务，无需重启内核。例外更新使用防火墙事务，只修改指定应用的规则，保留其他程序的阻断、内核放行及 Tailscale 保护。内核异常退出或自动恢复期间仍保留例外。
- 移除后新连接重新受保护，已有连接可能需要重新连接。已卸载应用不获放行，也不会阻止内核启动。本机例外不随备份迁移至其他电脑。
- **应用例外仅解除断网保护拦截，不会改变系统代理或 TUN 路由。** DNS 防泄漏独立生效，TUN/内核故障时不能据此保证远控联网。规则中的 DIRECT 同样先经过 TUN/内核。

## Prism 内核分级恢复

- 连续确认联网故障后，先重建 DNS 和代理会话、清理旧连接，保留 TUN 设备及断网保护；复测恢复正常则不重启进程。
- 会话恢复失败、API 无响应或复测仍不通时，再执行完整重启；保持手动停止取消和恢复频率限制。其他内核继续使用原有完整重启流程。
- 启用断网保护时，服务不可用或需要更新会报告错误，保持 TUN 设置，不再自动退回无 TUN 模式。

## 更新步骤

1. 安装新版并完整退出、重新打开 Prism。
2. **Windows 请在设置中“重新安装 / 更新内核”，更新 TUN 服务。** 应用例外需要新版服务；旧服务会提示更新，不会静默忽略配置。
3. 只为可信程序添加例外；需要远控在内核故障时仍可用，还需独立的路由或组网通路，不能仅依赖应用例外或 DIRECT。

macOS 包含共用的分级恢复改进；应用例外与 Windows WFP 断网保护仅适用于 Windows。本次优化恢复流程，未将此前未复现的长时间断网归因为已证实的 TUN 设备故障。
