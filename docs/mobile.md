# Prism 移动端方案

本文定义后续开发范围，不代表已实现移动端。当前正式安装包仅支持 Windows 和 macOS。

开发状态：暂停移动端开发，优先修复桌面自研 Prism 内核的 DNS 泄露与稳定性问题。

## 产品边界

手机端与电脑端分别设计界面、运行机制、设置和发布流程。移动端不追求桌面功能齐全；无法实现、实现成本过高或在目标系统上不稳定的功能不纳入该平台版本，不保留不可用的按钮、占位页或需要反复重启的兼容模式。

Android、iOS/iPadOS、原生鸿蒙各自适配系统 VPN 接口和应用生命周期，不要求三平台功能完全一致或同时发布。兼容安卓应用的旧版鸿蒙仅在完成对应设备验证后列为 Android 包的兼容设备，不能据此宣称支持原生鸿蒙。

## 首版保留范围

- 连接/断开、明确的运行状态与错误提示。
- 订阅导入、手动更新、单节点添加、节点选择和按需延迟测试。
- 基础规则分流；仅开放在对应平台实测通过的协议和配置。
- 系统 VPN 接管及配套 DNS 解析；DNS、IPv6 行为必须经过该平台验证，不能只靠界面开关宣称防泄漏。
- 简单的速度/流量显示、容量受限的本地诊断日志；日志隐藏订阅凭据和节点密钥。
- 使用系统支持的方式处理后台运行、网络切换和重连；重试有上限，用户手动断开后不自动连接。

首版界面以连接、节点/订阅、设置为主，不复制桌面完整导航。低频功能不维持后台轮询；不以持续探测和测速维持所谓在线状态。

## 不纳入移动端的桌面功能

- 独立 Tailscale 客户端管理、代理 VPN 与 Tailscale VPN 双开，以及桌面的守护进程/接口防火墙例外。移动端不为功能对齐引入嵌入式组网。
- Windows WFP、管理员/root 服务、桌面式内核进程管理、动态下载安装并切换多个内核。
- 按进程路径分流、进程级流量归属、连接地图、大量实时连接轮询及桌面连接导出工具。
- 局域网代理共享、WebDAV 后台同步、JavaScript 覆写脚本、复杂链式代理和桌面自动化。
- 基于“连接列表或流量不变”重启内核的桌面看门狗。移动端正常锁屏、系统挂起和省电限制不能作为故障依据。

这些功能不属于手机端默认路线；后续如需调整范围，须重新评估实际需求和目标系统的稳定实现条件。

## 按平台处理

| 平台 | 实现边界 |
| --- | --- |
| Android | 使用系统 VpnService 和生命周期机制；系统常开 VPN/阻止无 VPN 连接仅在实际支持并验证后提供指引，不用后台保活技巧替代系统能力。 |
| iOS/iPadOS | 使用 Network Extension；连接恢复、后台运行和分发遵循系统能力，不承诺任意后台进程、定时任务或永久断网保护。 |
| 原生鸿蒙 | 使用原生 VPN 扩展及应用生命周期；先验证 SDK、设备权限和分发条件，再决定是否进入实现，不用 APK 兼容容器充当原生支持。 |

共享 Rust 协议和配置代码以可移植性为前提，系统网络接入层分别实现；不通过 root、越狱、私有 API 或双 VPN 绕过平台限制。

## 配置和发布隔离

移动端使用独立设置模型和安装/更新渠道，不复用桌面 TUN 服务、系统路径或桌面安装包更新清单。共享订阅时只导入受支持的节点与规则；不支持的配置明确提示，无法保持关键路由或 DNS 语义时拒绝启用，不静默改成直连。

桌面现有功能不因移动端精简而移除。移动端文档和界面仅展示该平台已交付能力，不能将桌面验证结果当作移动端验证结果。

## 交付门槛

每个平台分别完成真机上的连接、DNS/IPv6 路由、Wi-Fi/蜂窝切换、锁屏、后台挂起、权限撤销和手动断开测试，并检查耗电与内存增长，再发布安装包。

对于不支持或无法稳定通过验证的可选功能，直接从该平台移除。若基础联网、解析或生命周期本身不稳定，则暂不发布该平台版本，不将自动重启当作稳定性的替代品。
