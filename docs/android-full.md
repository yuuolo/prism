# Android 完整版范围与验收

用户要求的完整手机版以本文清单为准。已发布的 `0.2.0-beta.1` 是基础增强版，尚未达到完整手机版范围。界面重做、多订阅管理和升级通知不代表下列功能已经交付。

| 功能 | 当前状态 | 完整版验收目标 |
| --- | --- | --- |
| 仪表盘 | 仅连接状态和会话上下行累计 | 运行时间、实时速率、连接数、当前策略、历史流量入口与真实内核状态 |
| 流量路由 | 内核执行基本规则，未提供可视化入口 | 查看连接目的地、网络类型、命中规则、出站链与流量；支持搜索、排序、筛选和关闭连接 |
| 网络工具 | 仅当前节点 HTTP 探测 | DNS 查询、网络连通与延迟检测；结果标明直连/经代理路径，错误可诊断 |
| 代理服务 | JNI 内核未启动 mixed 监听 | 明确启停的本机 HTTP/SOCKS5 服务，显示监听地址和端口并验证实际转发；共享范围单独设置和验证 |
| 广告拦截 | 未实现 | 可更新的拦截规则、用户例外、启停与命中统计；验证广告域名实际受阻及正常域名不受误伤 |
| 自动优选 | 仅手动选择一个节点 | 候选节点配置、探测结果、切换策略和失效回退；约束后台频率与候选规模，显示实际选择结果 |
| 流量统计 | 仅当前会话总量 | 实时速率、跨会话日/月统计、按节点/策略汇总和清零；说明统计口径与异常退出时的精度 |
| 地区分流 | 未实现 | 可验证的 GeoIP/GeoSite 数据与更新时间，地区规则优先级、默认出口及实际命中结果 |
| 订阅合并 | 多个来源独立保存，仅选择一个节点使用 | 来源选择、去重和冲突处理；合并节点仅进入“自动选择”和“节点选择”组，不污染其他策略组 |
| 路由规则 | 仅域名后缀与 IPv4 CIDR 直连 | 规则顺序、启停、编辑、导入、分组和目标策略；保存校验与真实规则命中检验 |
| 链式代理 | Android 配置层显式拒绝 | 明确的前置/后置节点和顺序、循环检测、协议能力校验；验证实际链路和 DNS 路径 |

## 实现顺序

1. 打通内核数据与控制：仪表盘、连接/路由详情、流量统计、DNS/网络检测、本机代理服务。
2. 建立策略配置：完整规则、自动优选、订阅合并、地区分流、广告拦截。
3. 接入链式代理并进行协议组合、断连、网络恢复与 DNS 防泄漏验证。

每一项分别记录实现、构建、模拟器验证及真机验证状态。仅新增入口、按钮、模拟数据或配置字段，不计为功能完成。

## 配置与运行要求

- 使用内嵌内核的真实数据与控制能力；应用无需开放管理 API 给外部应用。
- 完整策略配置与当前“单节点 + 直连规则”模型需要显式迁移，保留节点来源、收藏和已有设置。
- DNS 经代理、IPv6 接管和网络恢复必须随新路由及代理链一并验证，不能静默回退直连。
- 节点优选、规则更新和历史统计遵守 Android 后台与耗电约束；连接详情仅在需要时刷新。
- 安卓安装包与桌面更新通道继续独立，使用现有安卓签名覆盖更新。
